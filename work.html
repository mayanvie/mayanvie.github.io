I pick tools for findability and handoff. A shiny new app doesn't help much if someone else can't find the same file next month.

Systems

LMS & corporate systems

I haven't run an enterprise LMS in production yet. I do think like an ops teammate. Clear pathways, enrollments, completion signals. An experience that answers “what do I do today?” without a scavenger hunt.

I'm ready to learn tools like iLearn (or similar) quickly. The logic is familiar. Sequenced content, practice tasks, pass rules. The interface is what I'd need to learn.
